# BoreFormula 1.0.0 — Первый выпуск

Первый официальный выпуск инженерного калькулятора BoreFormula для Windows.

**Возможности:**
- Расчёт объёмов скважины и затрубного пространства.
- Цементирование и буровые растворы.
- Обсадные колонны и вытеснение.
- Гидростатическое давление.
- Производительность насосов и время циркуляции.
- Конвертер единиц измерения.
- История расчётов и экспорт в TXT.

**Free:** бесплатные инженерные расчёты.

**Pro:** подробные пошаговые решения, доступные после активации лицензии.

**Система:** Windows x64.

Основные расчёты работают без подключения к интернету.

Разработчик: HobbyLeaf Studio.

Программа предназначена для учебных и вспомогательных инженерных расчётов. Ответственные производственные решения требуют независимой проверки результатов.
